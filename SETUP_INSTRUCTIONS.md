## 💡 Tips:

- **Audio Quality**: Better audio quality = better transcription accuracy
- **File Size**: Larger files take longer to process
- **Language Settings**: Use "Translate to English" for Tamil, Hindi, or any non-English meetings
- **AI Selection**: Claude for complex meetings, GPT-4o for strategic analysis
- **Settings**: Use the settings panel to choose AI provider and language processing
- **API Limits**: Both APIs have rate limits, so very large files might take time
- **Error Handling**: Smart fallback system switches between AI providers if one fails

## 🛠️ Troubleshooting:

- **API Errors**: Check your internet connection and API key validity
- **Large Files**: Be patient - transcription can take several minutes
- **Browser Issues**: Use Chrome or Firefox for best compatibility
